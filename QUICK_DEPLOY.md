# Быстрый деплой TokenHunter - Пошаговая инструкция

## 🎯 Что нужно понять

**GitHub Actions** = автоматический сбор данных (уже работает) ✅
**Telegram Bot** = должен работать постоянно на сервере (нужно настроить) ⚠️

## 🚀 Варианты деплоя бота

### Вариант 1: Railway (самый простой, есть бесплатный план)

1. Зарегистрируйтесь на https://railway.app
2. Создайте новый проект
3. Подключите GitHub репозиторий `TimurSama/th_demo`
4. Добавьте переменную окружения:
   - `TELEGRAM_BOT_TOKEN` = `<TELEGRAM_BOT_TOKEN>`
5. Railway автоматически запустит бота из `main.py`

**Плюсы:** Бесплатно, просто, автоматический деплой
**Минусы:** Может засыпать на бесплатном плане

### Вариант 2: Render (бесплатный план)

1. Зарегистрируйтесь на https://render.com
2. Создайте новый Web Service
3. Подключите GitHub репозиторий
4. Настройки:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python main.py`
5. Добавьте переменную окружения `TELEGRAM_BOT_TOKEN`

**Плюсы:** Бесплатно, просто
**Минусы:** Может засыпать после 15 минут бездействия

### Вариант 3: VPS сервер (самый надежный)

**Рекомендуемые провайдеры:**
- Timeweb (Россия) - от 200₽/месяц
- DigitalOcean - $5/месяц
- Hetzner - €4/месяц

**Шаги:**
1. Арендуйте VPS
2. Подключитесь по SSH
3. Установите Python 3.11+
4. Клонируйте репозиторий
5. Создайте `.env` файл с токеном
6. Запустите через systemd (см. DEPLOYMENT.md)

**Плюсы:** Полный контроль, всегда работает
**Минусы:** Требует настройки, платно
